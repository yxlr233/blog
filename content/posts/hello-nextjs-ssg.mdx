You can mix Markdown with React components that are exposed by the site.
</Callout>

## Writing posts

Add a new `.mdx` file under `content/posts` and include the required frontmatter:

```mdx title="content/posts/my-first-post.mdx" {2-4} showLineNumbers
---
title: "Post title"
description: "Short summary for lists and metadata"
date: "2026-07-22"
tags: ["Notes"]
---
```

The build reads every post, sorts by date, and creates static routes for each slug.
