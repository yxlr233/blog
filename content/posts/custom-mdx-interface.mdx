MDX 的价值不只是把 Markdown 渲染成 HTML。它还允许文章直接使用站点暴露的组件，让教程、说明、笔记和项目记录拥有一致的界面语言。

<Callout title="按内容选择组件" type="tip">
优先使用普通 Markdown。只有当内容确实需要提示、对比、分步或折叠时，再使用 MDX 组件强化结构。
</Callout>

## 步骤

<Steps>
  <Step title="写 frontmatter">定义标题、摘要、日期、分类和标签。</Step>
  <Step title="组织正文">用 Markdown 写主体，用 MDX 组件补充结构。</Step>
  <Step title="构建导出">运行 `npm run build` 生成静态文件。</Step>
</Steps>
