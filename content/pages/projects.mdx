## 个人项目

这是一个使用 Next.js + MDX 静态导出的博客，支持自定义主题、深色模式、全文搜索、分类与标签系统。

<Callout title="如何添加自定义页面">
在 `content/pages/` 目录中创建一个 `.mdx` 文件，填写 `title`、`description` 和 `order` 字段，即可自动在 `/pages/{slug}/` 路由下生成该页面。
</Callout>

## 技术栈

- **Next.js 15** — App Router + 静态导出
- **MDX** — Markdown 与 React 组件混写
- **TypeScript** — 类型安全
- **Lucide React** — 图标库
