用 MDX 组合自定义界面

通过可复用组件把文章写成更接近文档系统的阅读体验。

WritingMDXComponentsInterface

MDX 的价值不只是把 Markdown 渲染成 HTML。它还允许文章直接使用站点暴露的组件，让教程、说明、笔记和项目记录拥有一致的界面语言。

按内容选择组件

优先使用普通 Markdown。只有当内容确实需要提示、对比、分步或折叠时，再使用 MDX 组件强化结构。

#内容概览

EmphasisCallout

用于提示、风险、结论和上下文补充。

ProcessSteps

用于安装、迁移、排障等有顺序的流程。

ReferenceTabs

把同一主题的不同平台或语言示例放在一起。

#提示块

Callout 支持五种语义类型：info tip success warning danger

构建成功

生产构建已经生成静态文件，可以部署 out/ 目录。

修改前先备份

迁移内容结构前，先确认文章 slug 和现有外链不会失效。

#步骤

  1. 写 frontmatter
    定义标题、摘要、日期、分类和标签。
  2. 组织正文
    用 Markdown 写主体，用 MDX 组件补充结构。
  3. 构建导出
    运行 npm run build 生成静态文件。
