Designing a Quiet Blog

A compact layout for reading, scanning, and publishing without extra surface area.

DesignDesignWriting

本页目录

  • Design choices
  • Static by default

A small blog works best when the structure stays predictable. This starter keeps the first screen focused on recent writing, then uses a plain archive page for everything else.

#Design choices

  • A narrow reading measure keeps long posts comfortable.
  • Borders and spacing do the organizational work.
  • Tags remain useful without turning into visual clutter.

#Static by default

generateStaticParams returns every post slug at build time, and output: "export" writes static assets to out/.
